# 🕌 Waktunya Kita Sholat

**Waktunya Kita Sholat** adalah aplikasi web sederhana untuk membantu pengguna melihat jadwal sholat, memantau waktu sholat berikutnya, mencatat absen sholat, dan melihat jadwal puasa sunnah.

Aplikasi ini dibuat menggunakan **HTML, CSS, dan JavaScript** dalam satu file.

## ✨ Fitur

- 🕌 Jadwal sholat realtime
- ⏳ Countdown menuju waktu sholat berikutnya
- 📍 Pilihan lokasi:
  - Jakarta
  - Tangerang
  - Tangerang Selatan
  - Bandung
  - Surabaya
- 👤 Input nama pengguna
- 👦👧 Pilihan gender
- 🌸 Mode Red Day
- ✅ Absen sholat
  - 🏠 Rumah
  - 🕌 Masjid
  - 🏫 Sekolah
- ⭐ Sistem poin
  - Rumah: 5 poin
  - Masjid: 10 poin
  - Sekolah: 10 poin
- 📜 Riwayat absen sholat
- 🌙 Kalender puasa sunnah
- 📱 Laporan sholat melalui WhatsApp
- 🛎️ Fitur notifikasi
- 💾 Penyimpanan data menggunakan LocalStorage
- 🔄 Update jadwal secara otomatis

## 🛠️ Teknologi

Project ini menggunakan:

- HTML5
- CSS3
- JavaScript
- LocalStorage
- AlAdhan API
- WhatsApp API

## 📱 Cara Menjalankan

1. Download atau clone repository ini.
2. Buka file `waktusholat.html`.
3. Jalankan menggunakan browser seperti Google Chrome, Microsoft Edge, atau Mozilla Firefox.
4. Masukkan nama saat aplikasi pertama kali dibuka.
5. Pilih gender dan gunakan fitur yang tersedia.
